### Claude:

The four fixes are done on three branches, grouped so that they apply to `main` without conflicts. Nothing is committed to `main` and nothing is pushed.

**The batches**

- `claude/preview-seed`: the seed field. The Preview section shows a text field that parses like the vanilla seed field, a number or a hashed string. An empty world seed gives a random number in the field. Reseed writes a new number. Done writes the field text into the world creation seed, so the player gets the seed they previewed. Cancel drops it.
- `claude/panel-scale`: the ImGui scale and the icons. The panel, its popups and the gizmo draw at one constant scale, and the popup icons render into the atlas at the pixel size of their row instead of 16 px upscaled.
- `claude/block-field-sequence`: wall, path, interior. Left to right in the menu, top to bottom in the panel. The settings data and JSON keep their sequence.

**Apply them in this sequence** (each is a no-commit cherry-pick; I verified the chain applies cleanly on a clean `main`):

```bash
git cherry-pick -n main..claude/preview-seed
```

```bash
git cherry-pick -n main..claude/panel-scale
```

```bash
git cherry-pick -n main..claude/block-field-sequence
```

The scale constant lives in [ImGuiPreviewPanel.java:59](src/main/java/us/drullk/aerolite/client/preview/imgui/ImGuiPreviewPanel.java:59) on the `claude/panel-scale` branch, as `FONT_SCALE = 1F`. The panel sets the ImGui main font scale to that value for its own draw and restores the imgui-mc value afterwards. The root cause is in imgui-mc 2.0.5 itself: it sets the ImGui font scale to the larger of the monitor content scale and half the GUI scale before every frame. With your display, scale 1 gives the 20 px JetBrains Mono that imgui-mc ships, which is ImGui's default look.

**Verification.** The combined tree compiles and the 43 JUnit tests pass. A muted client run with a temporary probe drove the screens and captured the window. The ImGui panel was pixel-identical at GUI scale 1 and 4 while the vanilla Done and Cancel buttons grew four times. The probe typed "hello world" in the preview and the world creation seed read "hello world" after Done. The icon atlas rendered proper 64 px block icons. Two things were not seen on screen: the new wall, path, interior sequence, and the icon popup in place. Both are small code changes that compiled; a look at the Shaft Variations section in the preview will confirm them.

**One overlap to know about.** All three batches touch the panel class, in different methods, plus the identical attribution Javadoc line. I moved the scale constant on its branch after a first trial pick conflicted with the seed branch's constant.
