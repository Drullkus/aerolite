### Claude:

Yes, you can get crisp pixel text. Scaling is not causing the soft text, so your Retina and external display setup can stay as it is.

**Why the text is soft now**

- imgui-mc 2.0.5 ships ImGui 1.92.7. Version 1.92 draws each glyph at its exact screen size, and the framebuffer scale is part of that size. So the texture is not stretched.
- The soft edges come from the default text engine (stb_truetype). It gives each edge pixel a partial gray value.
- imgui-mc loads JetBrains Mono with only `PixelSnapH` set. That setting snaps glyph positions to whole pixels. It does not turn the soft edges off.

**Path 1: a pixel font for the panel**

- Add a pixel-art TTF font to `assets/aerolite/imgui_font/`. imgui-mc loads fonts from that folder, and the panel switches to the font with `pushFont`.
- A pixel font is drawn on a grid. If the size is a whole multiple of that grid, every pixel of the glyph is fully on or off. No FreeType is needed.
- Only the panel changes. The Veil windows keep their font.
- `FONT_SCALE` must then go up in steps that match the font grid. A value such as 1.3 brings the soft edges back.
- You must pick a font whose license allows us to ship it, such as OFL or CC0.

**Path 2: FreeType monochrome on the current font**

- The native library has FreeType built in. The Java side has `ImFontAtlas.setFreeTypeRenderer(true)` and the flags `ImGuiFreeTypeLoaderFlags.Monochrome | MonoHinting`.
- This gives 1-bit glyphs at any size, so `FONT_SCALE` can stay free.
- The text engine is shared by every ImGui window, so the Veil windows change too. imgui-mc builds its own font settings, so the panel must clear the glyph cache after the switch.
- A smooth outline font like JetBrains Mono looks rough in 1-bit at small sizes. Thin lines can break, and curves can look jagged.

One more option is `RasterizerMultiply`. It makes the edges darker, but they stay gray, so it does not give a pixel look.

### Claude:

Yes. `RegisterImGuiFontsEventNeoforge` can give the preview panel its own font, and the Veil windows keep theirs.

**Why it works**

- imgui-mc fires the event on the mod bus each time it rebuilds the font atlas. The atlas is already cleared, and imgui-mc's fonts are already added (`ImGuiFontManagerImpl.rebuildFonts`).
- The event hands you the `ImFontAtlas`. You can add your own copy of JetBrains Mono with your own `ImFontConfig`.
- ImGui 1.92 reads the FreeType flags from each font's own `ImFontConfig`. Set `Monochrome | MonoHinting` on your copy, and only that font draws in 1-bit.
- The panel already calls `ImGui.pushFont(ImGui.getFont(), 0)`. It pushes your font instead. Veil windows keep the default font, so they keep the smooth text.

**About the FreeType loader**

- The native library is built with FreeType: `imgui_freetype.cpp` is compiled in. The `setFreeTypeRenderer` code is guarded by `#ifdef IMGUI_ENABLE_FREETYPE`.
- In ImGui 1.92, FreeType is the default loader when that flag is defined. So you do not need `setFreeTypeRenderer(true)`, and the shared loader stays the same.
- I inferred this from the build. I did not check it in a running client. The stb_truetype loader ignores the `Monochrome` flag, so the first test shows which loader is active. If the text is still smooth, stb_truetype is active.

**Details for the code**

- The atlas is rebuilt on each resource reload, so the `ImFont` reference changes each time. The panel must take the new font from each event.
- Read the font bytes from imgui-mc's own resource, `imguimc:imgui_font/jetbrains_mono-regular.ttf`. Then we ship no copy of the font.
- imgui-mc keeps its `ImFontConfig` objects alive until it frees the fonts. Our config needs the same lifetime.
- Give the new font the same pixel size as imgui-mc's font: 20 times the event's `getFontScale()`. Then the panel layout does not move.
- The listener uses imgui-mc types, so it goes in `us.drullk.aerolite.client.preview.imgui`. That is the package rule for ImGui code.

import foundry.imgui.api.ImGuiMC;
import imgui.ImFont;
import imgui.ImFontAtlas;
import imgui.ImFontConfig;
import imgui.ImGui;
import imgui.flag.ImGuiFreeTypeLoaderFlags;
import net.minecraft.client.Minecraft;
import net.minecraft.resources.ResourceLocation;
import us.drullk.aerolite.Aerolite;

import javax.annotation.Nullable;
import java.io.IOException;
import java.io.InputStream;

/**
 * The font of the preview panel: the imgui-mc default font, rasterized by FreeType as one-bit glyphs.
 * imgui-mc clears the atlas before each font event, so each event adds the font again.
 * The other ImGui windows keep the default font.
 *
 * <p>Written by Claude Code; conversation transcript: {@code llm/transcripts/transcript_2026-10-30_21-56_ad766c27-abc7-4f8b-ae6a-53b92f85435c.md}.
 */
public final class ImGuiPanelFont {

    private static final ResourceLocation SOURCE = ImGuiMC.FONT_DEFAULT.withPath(path -> "imgui_font/" + path + "-regular.ttf");
    private static final int LOADER_FLAGS = ImGuiFreeTypeLoaderFlags.Monochrome | ImGuiFreeTypeLoaderFlags.MonoHinting;

    /** The font in the current atlas. Null until the first font event, or when the source did not load. */
    @Nullable
    private ImFont font;

    /** Adds the font to the atlas at the size of the default font. */
    public void register(ImFontAtlas atlas, ImFont defaultFont) {
        this.font = null;
        byte[] bytes;
        try (InputStream stream = Minecraft.getInstance().getResourceManager().open(SOURCE)) {
            bytes = stream.readAllBytes();
        } catch (IOException e) {
            Aerolite.LOGGER.error("Failed to read the preview panel font {}", SOURCE, e);
            return;
        }
        ImFontConfig config = new ImFontConfig();
        try {
            config.setName("aerolite panel");
            config.setPixelSnapH(true);
            config.setFontLoaderFlags(LOADER_FLAGS);
            // The atlas copies the config and the font bytes.
            this.font = atlas.addFontFromMemoryTTF(bytes, defaultFont.getLegacySize(), config);
        } finally {
            config.destroy();
        }
    }

    /** The panel font, or the current font before the first font event. */
    public ImFont get() {
        return this.font != null ? this.font : ImGui.getFont();
    }

}

import foundry.imgui.api.ImGuiMC;
import imgui.ImFont;
import imgui.ImFontAtlas;
import imgui.ImFontConfig;
import imgui.ImGui;
import imgui.flag.ImGuiFreeTypeLoaderFlags;
import net.minecraft.client.Minecraft;
import net.minecraft.resources.ResourceLocation;
import us.drullk.aerolite.Aerolite;

import javax.annotation.Nullable;
import java.io.IOException;
import java.io.InputStream;

/**
 * The font of the preview panel: the imgui-mc default font, rasterized by FreeType as one-bit glyphs.
 * The imgui-mc renderer bakes each font once at its load size and scales it to the drawn size.
 * So the panel font loads at the drawn size, with the framebuffer scale as its rasterizer density.
 * imgui-mc clears the atlas before each font event, so each event adds the font again.
 * The other ImGui windows keep the default font.
 *
 * <p>Written by Claude Code; conversation transcript: {@code llm/transcripts/transcript_2026-10-30_21-56_ad766c27-abc7-4f8b-ae6a-53b92f85435c.md}.
 */
public final class ImGuiPanelFont {

    private static final ResourceLocation SOURCE = ImGuiMC.FONT_DEFAULT.withPath(path -> "imgui_font/" + path + "-regular.ttf");
    private static final int LOADER_FLAGS = ImGuiFreeTypeLoaderFlags.Monochrome | ImGuiFreeTypeLoaderFlags.MonoHinting;

    /** The drawn size of the panel text, in ImGui units. */
    private final float size;
    /** The font in the current atlas. Null until the first font event, or when the source did not load. */
    @Nullable
    private ImFont font;
    /** The framebuffer scale that the next font event bakes for. */
    private float density = 1;
    /** The framebuffer scale that the current font has. */
    private float bakedDensity = Float.NaN;

    public ImGuiPanelFont(float size) {
        this.size = size;
    }

    /** Adds the font to the atlas at the drawn size and the requested density. */
    public void register(ImFontAtlas atlas) {
        this.font = null;
        this.bakedDensity = this.density;
        byte[] bytes;
        try (InputStream stream = Minecraft.getInstance().getResourceManager().open(SOURCE)) {
            bytes = stream.readAllBytes();
        } catch (IOException e) {
            Aerolite.LOGGER.error("Failed to read the preview panel font {}", SOURCE, e);
            return;
        }
        // The binding cannot give one font its own loader, so the atlas uses FreeType for every font.
        atlas.setFreeTypeRenderer(true);
        ImFontConfig config = new ImFontConfig();
        try {
            config.setName("aerolite panel");
            config.setPixelSnapH(true);
            config.setFontLoaderFlags(LOADER_FLAGS);
            config.setRasterizerDensity(this.density);
            // The atlas copies the config and the font bytes.
            this.font = atlas.addFontFromMemoryTTF(bytes, this.size, config);
        } finally {
            config.destroy();
        }
    }

    /** Rebuilds the atlas when the framebuffer scale differs from the baked density. */
    public void matchDensity(float framebufferScale) {
        if (framebufferScale > 0 && framebufferScale != this.density) {
            this.density = framebufferScale;
        }
        if (this.density != this.bakedDensity) {
            // The rebuild sets the baked density, so one change requests one rebuild.
            this.bakedDensity = this.density;
            ImGuiMC.rebuildFonts();
        }
    }

    /** The panel font, or the current font before the first font event. */
    public ImFont get() {
        return this.font != null ? this.font : ImGui.getFont();
    }

    /** The drawn size of the panel text, in ImGui units. */
    public float size() {
        return this.size;
    }

}

import net.minecraft.resources.ResourceLocation;
import us.drullk.aerolite.Aerolite;

import javax.annotation.Nullable;
import java.io.IOException;
import java.io.InputStream;

/**
 * The font of the preview panel: the imgui-mc default font, rasterized by FreeType as one-bit glyphs.
 * The imgui-mc renderer bakes each font once at its load size and scales it to the drawn size.
 * So the panel font loads at the drawn size in framebuffer pixels, and each texel covers one pixel.
 * imgui-mc clears the atlas before each font event, so each event adds the font again.
 * The other ImGui windows keep the default font.
 *
 * <p>Written by Claude Code; conversation transcript: {@code llm/transcripts/transcript_2026-10-30_21-56_ad766c27-abc7-4f8b-ae6a-53b92f85435c.md}.
 */
public final class ImGuiPanelFont {

    private static final ResourceLocation SOURCE = ImGuiMC.FONT_DEFAULT.withPath(path -> "imgui_font/" + path + "-regular.ttf");
    private static final int LOADER_FLAGS = ImGuiFreeTypeLoaderFlags.Monochrome | ImGuiFreeTypeLoaderFlags.MonoHinting;

    /** The drawn size of the panel text, in ImGui units. */
    private final float size;
    /** The font in the current atlas. Null until the first font event, or when the source did not load. */
    @Nullable
    private ImFont font;
    /** The framebuffer scale that the next font event bakes for. */
    private float scale = 1;
    /** The framebuffer scale of the current font. NaN until a rebuild is requested. */
    private float bakedScale = Float.NaN;

    public ImGuiPanelFont(float size) {
        this.size = size;
    }

    /** Adds the font to the atlas at the drawn size in framebuffer pixels. */
    public void register(ImFontAtlas atlas) {
        this.font = null;
        this.bakedScale = this.scale;
        byte[] bytes;
        try (InputStream stream = Minecraft.getInstance().getResourceManager().open(SOURCE)) {
            bytes = stream.readAllBytes();
        } catch (IOException e) {
            Aerolite.LOGGER.error("Failed to read the preview panel font {}", SOURCE, e);
            return;
        }
        // The binding cannot give one font its own loader, so the atlas uses FreeType for every font.
        atlas.setFreeTypeRenderer(true);
        ImFontConfig config = new ImFontConfig();
        try {
            config.setName("aerolite panel");
            config.setPixelSnapH(true);
            config.setFontLoaderFlags(LOADER_FLAGS);
            // The atlas copies the config and the font bytes.
            this.font = atlas.addFontFromMemoryTTF(bytes, this.size * this.scale, config);
        } finally {
            config.destroy();
        }
    }

    /** Requests one atlas rebuild when the framebuffer scale differs from the baked scale. */
    public void matchScale(float framebufferScale) {
        if (framebufferScale > 0) {
            this.scale = framebufferScale;
        }
        if (this.scale != this.bakedScale) {
            this.bakedScale = this.scale;
            ImGuiMC.rebuildFonts();
        }
    }

    /** The panel font, or the current font before the first font event. */
    public ImFont get() {
        return this.font != null ? this.font : ImGui.getFont();
    }

}

**What I found while I built it**

- **My earlier claim was wrong.** FreeType was not the active loader. stb_truetype was, so the `Monochrome` flag alone did nothing.
- **Shrinking also caused the gray edges.** The imgui-mc renderer for 1.21.1 bakes each font once, at its load size. imgui-mc loads fonts at 20 px, and the panel draws at 13 px. The texture was shrunk at draw time, so edges went gray and thin lines broke.

**What the change does**

- `ImGuiPanelFont` adds a copy of JetBrains Mono on each imgui-mc font event, with `Monochrome | MonoHinting`.
- The font bakes at the drawn size × the framebuffer scale. So each glyph texel covers one screen pixel.
- `ImGuiPreviewPanel` pushes this font at `FONT_SIZE`, which is 13. A change of the framebuffer scale, such as a move between a Retina and an external display, rebuilds the atlas once.
- I did not use `RasterizerDensity`. ImGui 1.92.7 multiplies it in twice in this bake path.
- `CLAUDE.md` has new bullets for these facts in the Preview section.

**One trade-off**

The imgui-java binding has no setter for a per-font loader. So the panel sets FreeType as the loader for the whole atlas. The Veil fonts keep their soft edges, but FreeType now draws them instead of stb_truetype. Their hinting and stroke weight can look a little different.

**Checks**

- The JUnit tests pass.
- All 7 GameTests pass.
- Data generation runs and leaves the generated files unchanged.
- I ran the client 5 times with a temporary probe that captures the screen. I deleted the probe before the commit.
- The test window ran at framebuffer scale 1. I did not test Retina at scale 2, and I did not look at the Veil windows.
