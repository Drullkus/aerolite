### Claude:

Here is what I found, then the Earth references, then the first question round.

**State of the work.** Nothing of 0.5.0 is Java yet. The `voronoi` branch is eight prototype commits over `main`. The handoff on `claude/islands-handoff` lists the open picks in its section 5, and every shape README ends with a "Choices for the owner" list that you have not answered. So re-planning costs no Java rework.

**What makes the "blobs with veins".** Two separate rules produce it:

- **Inner cells as scaled blobs.** Each inner cell is shrunk to its fill and rounded. A hard union leaves gaps between the pebbles. A smooth union fills the gaps with necks, which read as veins. The asteroid "cobble" and the lake bowl "half blob" use this.
- **Island cell merge "drop the shared face".** Each cell grows toward its neighbor until another wall stops it. The join is a gap, a step or a thin sliver. The slivers are real solid, not render noise.

**Full inner cells.** An inner cell is then solid as a whole or air as a whole. Inner cells tile space exactly, so a union of full cells has no gap and no neck, and a merged pair needs no face rule at all. The consequences: every surface is a set of flat facets of inner cell size, the silhouette of a shape resolves in steps of one inner cell, and surface relief needs a second step on top. The existing render `render-inner-center.png` in `prototypes/voronoi/images/` shows that look.

**Earth references for the candidate looks:**

- Faceted full-cell surfaces, columnar basalt: [Giant's Causeway, Northern Ireland](https://commons.wikimedia.org/wiki/File:Causeway-code_poet-4.jpg) and [Devils Postpile, California](https://commons.wikimedia.org/wiki/File:Devils_Postpile_National_Monument.jpg).
- Flat polygon cells with cracks: [Tessellated Pavement, Eaglehawk Neck, Tasmania](https://commons.wikimedia.org/wiki/File:Tessellated_Pavement_Sunrise_Landscape.jpg), [salt polygons of the Salar de Uyuni, Bolivia](https://commons.wikimedia.org/wiki/Category:Salar_de_Uyuni), [patterned ground, periglacial polygons](https://commons.wikimedia.org/wiki/Category:Patterned_ground).
- Islands that stay separate, no merge: [Stockholm archipelago skerries](https://commons.wikimedia.org/wiki/Category:Stockholm_archipelago), [Ha Long Bay karst islands, Vietnam](https://commons.wikimedia.org/wiki/Category:Ha_Long_Bay).
- Two islands joined by a land neck: [tombolos](https://commons.wikimedia.org/wiki/Category:Tombolos).
- Lake bowl alternatives to the crater lake: [tarns, glacial rock basins](https://commons.wikimedia.org/wiki/Category:Tarns).

    /** The reach of the wall search around a cell, in lattice steps. With a jitter of 1 or less, the block of this reach holds every wall. */
    public static final int REACH = 2;

    private static final int SITE_SALT = 0x5173;
    private static final double UNIT = 1.0 / (1 << 21);

    /** One cell: its lattice index and its site. */
    public record Cell(int ix, int iy, int iz, double siteX, double siteY, double siteZ) {
    }

    /** The gauge at one point and the half spacing of the cell. The half spacing is the shortest site to wall distance along a site pair. */

    }

/**
 * Checks the island density: positive at the site of a filled cell, negative outside the row 0 and in an empty cell.
 *
 * <p>Written by Claude Code; conversation transcript: {@code llm/transcripts/transcript_2026-11-07_01-04_30006f9a-885c-4e1b-8259-941ec5aa5133.md}.
 */
class VoronoiIslandsTest {

    private static final DensityFunction.NoiseHolder NOISE = new DensityFunction.NoiseHolder(Holder.direct(new NormalNoise.NoiseParameters(-7, 1.0)));
    private static final VoronoiIslands ISLANDS = new VoronoiIslands(NOISE, 256, 128, 0, 0.8, 0.3, 0.9, 0.1);

    @Test
    void filledCellIsSolidAtItsSiteAndHollowOnItsWall() {
        int filled = 0;
        int empty = 0;
        for (int ix = -6; ix <= 6; ix++) {
            for (int iz = -6; iz <= 6; iz++) {
                VoronoiLattice.Cell cell = ISLANDS.lattice().cell(ix, 0, iz);
                double atSite = ISLANDS.compute(cell.siteX(), cell.siteY(), cell.siteZ());
                if (ISLANDS.hasIsland(cell)) {
                    filled++;
                    double fill = ISLANDS.fill(cell);
                    assertTrue(fill >= 0.3 && fill <= 0.9, "The fill left its bounds");
                    assertTrue(atSite > 0, "A filled cell is hollow at its site");
                    double wallX = cell.siteX();
                    VoronoiLattice.Gauge gauge = ISLANDS.lattice().evaluate(cell, wallX, cell.siteY(), cell.siteZ());
                    assertEquals(fill * gauge.halfSpacing(), atSite, 1e-9, "The density at the site is not the fill times the half spacing");
                } else {
                    empty++;
                    assertEquals(ISLANDS.minValue(), atSite, "An empty cell is solid at its site");
                }
            }
        }
        assertTrue(filled > 100, "Too few filled cells");
        assertTrue(empty > 0, "No empty cell");
    }

    @Test
    void rowsAboveAndBelowHoldNoIsland() {
        for (int ix = -6; ix <= 6; ix++) {
            for (int iy : new int[] {-2, -1, 1, 2}) {
                VoronoiLattice.Cell cell = ISLANDS.lattice().cell(ix, iy, 0);
                assertEquals(ISLANDS.minValue(), ISLANDS.compute(cell.siteX(), cell.siteY(), cell.siteZ()), "A cell outside the row 0 is solid");
            }
        }
    }

    @Test
    void densityStaysInsideItsBoundsAndIsNegativeOutsideTheIsland() {
        Random random = new Random(4);
        for (int i = 0; i < 2000; i++) {
            double x = (random.nextDouble() - 0.5) * 2048;
            double y = (random.nextDouble() - 0.5) * 512;
            double z = (random.nextDouble() - 0.5) * 2048;
            double density = ISLANDS.compute(x, y, z);
            assertTrue(density >= ISLANDS.minValue() && density <= ISLANDS.maxValue(), "The density left its bounds");
            VoronoiLattice.Cell cell = ISLANDS.lattice().nearest(x, y, z);
            double gauge = ISLANDS.lattice().evaluate(cell, x, y, z).value();
            boolean inside = ISLANDS.hasIsland(cell) && gauge < ISLANDS.fill(cell);
            assertEquals(inside, density > 0, "The sign of the density does not match the scaled cell");
        }
    }

    @Test
    void contextComputeMatchesThePointCompute() {
        assertEquals(ISLANDS.compute(10, 20, 30), ISLANDS.compute(new DensityFunction.SinglePointContext(10, 20, 30)));
    }

}

    private final int searchReachY;

    private final int wallReachY;

    }

    public VoronoiLattice(long seed, int cellSize, int cellHeight, int layerMinY, double jitter) {
        this.seed = seed;
        this.cellSize = cellSize;
        this.cellHeight = cellHeight;
        this.layerMinY = layerMinY;
        this.jitter = jitter;
        // A point is at most this far from its own site, so its nearest site is nearer.
        double offset = 0.5 + jitter / 2;
        double farthest = Math.sqrt(2 * (offset * cellSize) * (offset * cellSize) + (offset * cellHeight) * (offset * cellHeight));
        this.searchReachXZ = searchReach(farthest, cellSize, offset);
        this.searchReachY = searchReach(farthest, cellHeight, offset);
        // Every point of a cell is within that distance of its site, so a wall site is within twice that distance.
        this.wallReachXZ = searchReach(2 * farthest, cellSize, jitter);
        this.wallReachY = searchReach(2 * farthest, cellHeight, jitter);

A jittered 3D lattice of boxes, 256 wide and 128 tall from Y 0, holds one site per box. Only the row 0 holds islands. An island is its 3D Voronoi cell scaled about its site by a seeded fill fraction between 0.3 and 0.9. One cell in ten stays empty. The JSON of each dimension holds those values, so you can edit them in the data.

**The surface at the island edges**

The cause was in the vanilla surface rules, not in the islands. The rules take the preliminary surface level of the four 16-block grid corners around a block and lerp them. A corner outside every island has no level, so it reads `Integer.MAX_VALUE`. The lerp then lifts the minimum surface level above the whole edge band, and the rules skip it.

The fix is a surface floor in the initial density of each island dimension. The floor is a Y gradient from 1 at the bottom of the dimension to -1 four blocks up, under a `max` with the island function. Every column now has a preliminary surface level, and the top view shows grass out to the edge. The final density does not hold the floor, so it places no block. A GameTest checks both facts in all three dimensions.

**The distortion**

The island function in [VoronoiIslands.java](src/main/java/us/drullk/aerolite/world/island/VoronoiIslands.java) shifts its input position by fractal simplex noise, one channel per axis, before the lattice lookup. Three new JSON fields set it:

- `distortion`: the largest shift in blocks. The shipped value is 12.
- `distortion_scale`: the wavelength of the first octave in blocks. The shipped value is 64.
- `distortion_octaves`: the octave count. The shipped value is 3. Each further octave halves the amplitude and the wavelength.

The warp noise seeds from the lattice seed, so the world seed drives it. The JUnit tests check the shift bound, the identity at zero, the copy and the codec round trip.
