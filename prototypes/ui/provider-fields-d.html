Option D: a tab per opened field

The variation box has a tab bar. The tab Blocks holds the block fields. Each opened field has its own tab with the provider editor.

The arrow button of a field opens the tab of that field. When the tab is open, the arrow selects it. The arrow never closes a tab. The cross on a tab is the only way to close it. A click on the summary of a field that is not a simple state also opens or selects its tab. A simple state keeps its text field and its dropdown. A click in that field only edits the text. The Blocks tab looks the same with any set of open tabs.

Each box shows one provider type in the field Wall and a simple state in the field Path. The text under each box is the JSON of the two fields, as the variation codec writes it.
