Block state provider fields

Each block field of a variation holds a block state provider of Minecraft 1.21.1. A closed field shows one line: the arrow button, then a summary. A simple state keeps its text field on that line. The arrow button opens the editor: the type combo, then the widgets of the type. Each section shows one design for the place of the editor. Each box shows one provider type in the field Wall. The text under each box is the JSON of that field.
